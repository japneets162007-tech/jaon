# Horizon Site

This is a Vite + React + TypeScript wrapper around the uploaded Horizon hero component.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite (usually http://localhost:5173).

## Deploy

Push this folder to GitHub and import the repo into Vercel or Netlify. The build command is `npm run build` and the output directory is `dist`.
